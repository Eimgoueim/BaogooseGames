【背景音乐】
· 主界面是温馨的纯音乐，进「🎮 宠物地牢」会自动换成激动的战斗音乐
· 宠物叫声比音乐声大（音乐 0.10 / 叫声 0.34），叫的时候音乐还会自动压低一下
· 左下角 🎵 按钮可以随时开关音乐，开关会存进存档

﻿屏幕做成了拓麻歌子 LCD 的样子：点阵颗粒质感 + 屏幕内阴影，右上角留了屏幕边。
整个界面就是拓麻歌子：房间铺满窗口，功能全部做成围着房间的两排图标（画在屏幕上、鼠标可点）。
上排（功能页面）：商店 / 背包 / 佩饰 / 房间 / 抽卡 / 积分 / 领养 / 存档 / 风格 —— 点一下就在屏幕上打开对应页面（带关闭键）。
下排（宠物操作）：喂食 / 玩耍 / 洗澡 / 睡觉 / 打工 / 抚摸 / 游戏 —— 点一下直接对宠物生效；不可用时图标会自动变灰并说明原因。
左上角浮着状态条与信用点/积分/背包数量；右上是宠物槽（切换多只宠物）；右侧竖排是喂食/使用栏；左下是宠物信息（含改名）。宠物可以用鼠标拖动：按住宠物拖到房间任何位置（会自动限制在房间内），拖动时它会闭眼、头顶冒三根小刺表示不耐烦，松手后约 2 秒才消气。
轻点房间（不拖）就是抚摸，会冒像素爱心。宠物形象：包鹅是一个白色椭圆球（六像素方嘴 + 四个一像素小脚）；小龙、小猫咪是 Q 版小动物；小鸟游星野（左蓝右黄异色瞳）、蓝色大肥鱼、GPT、Claude、Gemini 是二次元 Q 版像素角色。
宠物选择图标（领养列表 / 宠物槽 / 卡池）都用同一套像素宠物图。
房间布置：商店「🛋️ 家具」买家具，抽卡抽装饰品；进「🛋️ 房间」点「开始布置」，拖动改位置、滚轮或 ＋/－ 调大小，「收回」收进仓库。
抽卡：4 个限定卡池，1.5% 出当期限定；每池都有概率「歪」出小鸟游星野（初始不可领养，只能抽）。
保底：50 抽小保底必出限定（其中 60% 歪星野、40% 当期）；100 抽大保底必出当期限定。抽卡动画：出宠物放彩虹，没出飘云朵。
佩戴饰品照旧（会直接画在宠物身上）。界面风格（6 套配色 + 自定义主色）全部保留。🐾 宠物养成游戏 · 使用说明
================================================

【怎么玩】
双击同目录下的 Play.cmd（绿色版里叫「启动游戏.cmd」）即可开始游戏。
它会把游戏放在一个独立窗口里打开（无浏览器地址栏，像个小程序）。
如果系统里没有 Edge，会自动改用默认浏览器打开 PetGame.html。
游戏厅里有 9 个小游戏（接飞盘/记忆翻牌/靶心连击/连点挑战/心算速答/打地鼠/记忆序列/气球爆破/反应测试）。
宠物右侧的竖栏是喂食/使用栏，点一下就有喂食动画；点场景是抚摸。
饰品分两种：房间里的「装饰品」和戴在宠物身上的「佩饰」（佩饰页可以随时戴上/脱下）。
右上角「🎨 风格」可以换 6 套配色（樱粉/深海蓝/森林绿/陶土橙/薄荷青/暗夜黑），
还能自定义主色；配色会一起存进存档。

【装在哪里】
默认安装位置：%LOCALAPPDATA%\PetGame
桌面和开始菜单都会生成「宠物养成游戏」快捷方式。
想卸载：开始菜单里的「宠物养成游戏 卸载」，或者
      设置 → 应用 → 已安装的应用 → 宠物养成游戏 → 卸载。

【存档在哪 / 怎么备份】
· 自动保存：每次操作后 + 每 10 秒，存在浏览器数据目录
  （安装目录下的 browser 文件夹）。
· 手动备份：游戏里点右上角「💾 存档」→「导出到文本框」或「下载 .json」，
  把 JSON 复制保存下来即可；换电脑后在同一个面板「导入存档」粘贴回去。
· 注意：卸载会删除安装目录，也就删掉了存档，卸载前建议先导出备份。

【常见问题】
Q: 双击安装包时 Windows 提示"已保护你的电脑"/SmartScreen？
A: 这是自解压安装包的正常提示（没有花钱买代码签名证书）。
   点「更多信息」→「仍要运行」即可。

Q: 需要联网吗？
A: 不需要。整个游戏就是一个 HTML 文件，断网也能玩。

Q: 需要装别的软件吗？
A: 不需要。安装包是 Windows 自带工具打的，游戏用的是系统自带浏览器内核。
